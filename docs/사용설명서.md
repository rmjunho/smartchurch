# 스마트처치 사용설명서

> 앱을 **처음 쓰는 분**이 순서대로 따라 할 수 있게 만든 안내서입니다.
> 앱이 무엇인지 궁금하시면 [앱소개.md](앱소개.md) 를 먼저 보세요.

---

## 1. 가입하고 들어오기

### ① 회원가입

**[smartchurch.kro.kr](https://smartchurch.kro.kr)** 접속 → 로그인 화면 아래 **회원가입 →**

입력 항목:

- 이름(실명), 생년월일, 전화번호, 이메일
- 비밀번호 **8자 이상** + 비밀번호 확인
- **약관 동의** — 필수 항목 체크 후, `만 14세 이상` / `만 14세 미만(보호자 동의)` 중 **하나 선택**
  - 만 14세 미만이면 **보호자 이름·연락처 입력이 필수**로 추가됩니다

> 입력한 생년월일과 나이 선택이 서로 다르면 가입되지 않습니다.

### ② 온보딩 STEP 1 / 2 — 소속 선택

먼저 **교회 / 기관·단체 / 개인** 중 하나를 고릅니다.

| 내 상황 | 할 일 |
|---|---|
| 우리 교회가 이미 스마트처치를 쓴다 | **교회 코드 6자리** 입력 (예: `SC0001`) → 교회 이름이 확인되면 연결 완료 |
| 리더에게 초대 코드를 받았다 | 아래 `초대 코드 입력 →` 에서 **8자리** 입력 → 승인 없이 바로 입장 |
| 내가 교회·기관을 새로 만든다 | 아래 `교회 등록 →` 에서 원하는 코드와 이름 입력 |
| 아직 교회가 없다 | **개인** 선택 → 나중에 설정에서 언제든 가입 가능 |

이어서 **직분 선택** → **다음 →**

### ③ 온보딩 STEP 2 / 2 — 첫 챌린지

관심 있는 챌린지를 **최대 3개**까지 고르고 **완료! →**

### ④ 승인 대기 (⏳ 화면이 뜨면)

교회 코드로 가입하면 리더의 승인이 필요합니다. 승인되면 **자동으로** 앱 안으로 들어갑니다.
초대 코드로 들어온 경우에는 이 단계가 없습니다.

## 2. 매일 쓰기 — 삶의 예배 (첫 번째 탭)

### 날짜 고르기

상단 날짜 줄에서 `‹` `›` 로 주 단위 이동, 달력 아이콘으로 특정 날짜를 선택합니다.

### 기록 방식 3가지

상단 칩으로 전환하며, 언제든 바꿀 수 있습니다.

| 칩 | 설명 |
|---|---|
| **텍스트형** | 키보드로 입력 |
| **드로잉형** | 손글씨. `✏` 버튼으로 펜 · 형광펜 `🖍` · 지우개 `🧹` · 선택/이동 `⬚` · 손 `✋` 전환, 굵기와 색 조절 |
| **업로드형** | 종이에 쓴 것을 사진으로 올리기 |

### 기록 항목

각 항목의 제목을 누르면 접었다 펼 수 있습니다.

- 📖 **말씀 묵상** — 성경 본문 / 묵상 / 오늘의 적용 / 기도 제목
- ✅ **Todo List** — `⚙` 로 카테고리 관리
- 🗓 **시간표** — `⚙` 로 설정, 행 높이는 오른쪽 아래 손잡이로 조절
- 📓 **일기**
- 📝 **메모**

> **저장 버튼은 없습니다.** 입력하면 항목 오른쪽 위에 `저장됨` 이 표시됩니다.
>
> 드로잉형에서 매번 그리는 양식(표 선 등)은 **`기본값으로 저장`** 해두면 다음 날부터 자동으로 깔립니다.

## 3. 챌린지 (두 번째 탭)

1. `모든 챌린지` 에서 원하는 챌린지를 골라 신청합니다
2. 매일 카드의 **`오늘 체크하기`** 를 누르면 **`오늘 완료!`** 로 바뀝니다
3. 카드에 진행률 막대와 `D-7` 같은 남은 기간이 표시됩니다
4. 목표를 다 채우면 **`목표 달성!`**, 기간이 지나면 **`기간 종료`** 로 바뀝니다
5. 완료한 챌린지는 **마이 페이지 → 완료된 챌린지** 에 쌓입니다

---

## 4. 친구와 채팅 (세 번째 탭)

### 친구 추가하기

1. `친구` 탭 → **+ 친구 추가**
2. 상대의 친구 코드(`SC-****`)를 입력합니다
3. 내 코드는 **마이 페이지 → 나의 친구 코드 → 복사** 에서 확인합니다

### 대화하기

| 내부 탭 | 내용 |
|---|---|
| 채팅 | 1:1·그룹 대화. `🖼️` 로 사진 전송, `⋮` 로 방 설정 |
| 오픈채팅 | 우리 교회 공개 채널 *(교회 가입 후 사용 가능)* |
| 회의 | 모임·회의방 |

원치 않는 상대는 `친구` 탭의 **차단** 에서 관리합니다.

## 5. 교회 (네 번째 탭)

- 교회 소개·위치·목사님 프로필 보기
- **행사·모임** — `전체보기 ›` 에서 둘러보고 신청하거나 취소
- **게시판** 읽고 쓰기
- **함께할 사람 찾기** — 취미 모임 / 기도 / 멘토링 / 이성 매칭

## 6. 메뉴 ☰ (오른쪽 위)

| 묶음 | 항목 |
|---|---|
| 내 활동 | 내가 신청한 챌린지 · 내가 예약한 행사 · 내가 함께하는 매칭 |
| 게시판 | 앱 소식 · 건의함 |
| 교회 | 교회 정보 / 코드 변경 |
| 리더 전용 | 교인 관리 · 챌린지 관리 · 초대 코드 관리 · 행사 관리 |
| 그 외 | 앱 설정 · 로그아웃 |

---

## 7. 설정과 개인정보

### 메뉴 ☰ → 앱 설정

- **계정 정보 변경** — 이메일·비밀번호 변경 (현재 비밀번호 입력 필수)
- **삶의 예배 설정 → 리더에게 공유**
  - **기본값은 비공개** 입니다
  - 켜면 `리더에게 공유할 항목 선택` 이 나타나고, **체크한 항목만** 리더가 볼 수 있습니다

### 마이 페이지 → 프로필 공개

토글을 끄면 친구 코드로 검색되어도 프로필이 보이지 않습니다.

## 8. 막힐 때

| 증상 | 해결 |
|---|---|
| 교회 코드를 모르겠어요 | 담임 목사님이나 교회 리더에게 문의하세요. 코드 없이 **개인**으로 먼저 시작할 수 있습니다 |
| 승인 대기 화면에서 안 넘어가요 | 교회 리더가 승인해야 넘어갑니다. 초대 코드가 있다면 바로 입장할 수 있습니다 |
| 오픈채팅이 안 보여요 | 교회 가입이 필요합니다 → 메뉴 ☰ → 교회 정보 / 코드 변경 |
| 챌린지 체크 버튼이 눌리지 않아요 | 오늘 이미 체크했거나, 목표를 달성했거나, 기간이 끝난 챌린지입니다 |
| 리더 메뉴가 안 보여요 | 직분 선택만으로는 권한이 부여되지 않고 **앱 관리자 승인**이 필요합니다 |
| 교회를 옮겼어요 | 메뉴 ☰ → 교회 정보 / 코드 변경 |
| 기록이 저장됐는지 모르겠어요 | 항목 오른쪽 위 `저장됨` 표시를 확인하세요. 따로 저장 버튼은 없습니다 |
