# 스마트처치 색상 팔레트

> 실제 정의는 [css/style.css](../css/style.css) 의 `:root` 에 있습니다. 색을 바꿀 때는 **거기를 고치고 이 표를 맞춰 주세요.**

| 변수 | 색상 코드 | 용도 |
|---|---|---|
| `--gold` | `#C9A96E` | 포인트 색 (강조, 링크, 배지) |
| `--black` | `#0D0D0D` | 기본 텍스트, 주요 버튼 |
| `--dark` | `#1C1C1C` | 어두운 배경 |
| `--dark2` | `#2A2A2A` | 어두운 배경 (한 단계 밝게) |
| `--cream` | `#F2EDE5` | 앱 기본 배경 |
| `--cream2` | `#E8E1D8` | 카드 안쪽 배경 |
| `--cream3` | `#DDD6CC` | 카드 안쪽 배경 (한 단계 진하게) |
| `--white` | `#FFFFFF` | 카드 배경 |
| `--muted` | `#888888` | 보조 텍스트, 설명 문구 |
| `--border` | `#D5CFCA` | 테두리, 구분선 |
| `--danger` | `#D64545` | 경고, 삭제, 오류 |
| `--success` | `#4A9B6F` | 완료, 승인 |

## 포인트 색 변형

골드는 투명도를 얹어 배경·테두리로도 씁니다.

| 쓰임 | 값 |
|---|---|
| 연한 배경 | `rgba(201, 169, 110, 0.1)` |
| 테두리 | `rgba(201, 169, 110, 0.4)` |
