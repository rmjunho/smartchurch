# 스마트처치 앱 소개

> 스마트처치를 처음 접하는 분께 앱을 설명할 때 쓰는 문서입니다.
> 개발 문서가 아니라 **사용자 안내용** 입니다. (개발 안내는 [CLAUDE.md](../CLAUDE.md) 참고)
> 실제 사용 방법은 [사용설명서.md](사용설명서.md) 를 보세요.

---

## 한 줄 소개

**스마트처치** — 묵상, 챌린지, 교회 소통을 한곳에 모은 교회 커뮤니티 앱.
설치 없이 **[smartchurch.kro.kr](https://smartchurch.kro.kr)** 에서 바로 사용합니다.

## 세 줄 소개

매일의 묵상을 나만의 바인더에 기록하고,
교회 식구들과 챌린지·행사·채팅으로 함께하고,
교회 코드 하나로 우리 교회에 연결됩니다.

---

## 화면 5개

### 1. 삶의 예배 — 날짜별 신앙 바인더

- 오늘의 말씀과 함께 묵상 기록: **성경 본문 / 묵상 / 오늘의 적용 / 기도 제목**
- **Todo List · 시간표 · 일기 · 메모** 까지 한 페이지에서
- 기록 방식 3가지
  - **텍스트형** — 키보드로 입력
  - **드로잉형** — 손글씨. 펜·형광펜·지우개·선택 이동 지원, 자주 쓰는 양식은 "기본값으로 저장"
  - **업로드형** — 사진으로 올리기
- **나눔** — 리더에게 묵상을 공유하면 코멘트를 받을 수 있어요

### 2. 챌린지 — 신앙 습관 만들기

- **AI 추천** 이번 주 챌린지
- 내가 진행하고 있는 챌린지
- 모든 챌린지 (카테고리 필터)
- 완료한 챌린지는 마이 페이지에 기록으로 쌓입니다

### 3. 채팅

| 내부 탭 | 내용 |
|---|---|
| 친구 | 친구 코드로 추가, 차단 관리 |
| 채팅 | 1:1 DM·그룹 대화, 사진 전송 |
| 오픈채팅 | 우리 교회 공개 채널 |
| 회의 | 모임·회의방 |

### 4. 교회 *(기관·개인으로 가입하면 탭 이름이 바뀝니다)*

- 교회 소개·위치·목사님 프로필
- **행사·모임** 둘러보고 신청/취소, 내 신청 현황 확인
- **게시판**, 교인 현황
- **함께할 사람 찾기** — 취미 모임 / 기도 / 멘토링 / 이성 매칭
- 리더에게만 보이는 기능
  - 교인 관리, 초대 코드 발급
  - 교인 묵상 바인더 열람 및 코멘트
  - 우리 교회 챌린지 개설

### 5. 마이 페이지

- 프로필, 완료한 챌린지, 나의 교회 요약
- **나의 친구 코드**(`SC-****`) 복사 + 프로필 공개 여부 토글

## 시작하는 법 (온보딩 2단계)

**STEP 1 — 소속 선택** (교회 / 기관·단체 / 개인)

| 상황 | 방법 |
|---|---|
| 교인 | 담임 목사님께 받은 **교회 코드 6자리** 입력 → 승인 후 입장 |
| 초대 코드를 받았다면 | **초대 코드 8자리** 입력 → 승인 없이 바로 입장 |
| 목사님·전도사님 | 원하는 코드와 이름으로 **새 교회·기관 직접 등록** |
| 아직 교회가 없다면 | **개인으로 시작** → 나중에 설정에서 언제든 가입 |

**STEP 2 — 첫 챌린지 최대 3개 선택** → 완료

> 리더 권한은 직분을 선택하는 것만으로 부여되지 않고, **앱 관리자 승인**을 거칩니다.

## 어떤 분께 좋은가

| 대상 | 쓰는 이유 |
|---|---|
| 교인 | 묵상·QT 기록이 흩어지지 않고 날짜별로 쌓입니다 |
| 청년·학생 | 챌린지로 신앙 습관, 채팅·매칭으로 교회 안에서 관계 맺기 |
| 리더·교역자 | 교인 묵상에 코멘트, 행사 신청 현황, 교인 관리를 한곳에서 |
| 소규모 교회 | 서버도 앱 설치도 없이 코드 하나로 우리 교회 개설 |

## 자주 묻는 질문

**앱을 설치해야 하나요?**
아니요. 웹 주소로 바로 들어가면 됩니다. 홈 화면에 추가하면 앱처럼 쓸 수 있어요.

**교회 코드를 모르는데요?**
담임 목사님이나 교회 리더에게 문의하세요. 코드 없이도 **개인**으로 먼저 시작할 수 있습니다.

**내 묵상을 다른 사람이 볼 수 있나요?**
'나눔'으로 공유한 것만 리더가 볼 수 있습니다. 공유하지 않은 기록은 나만 봅니다.

**전화번호 같은 개인정보는요?**
연락처는 본인, 같은 교회 리더, 앱 관리자만 볼 수 있도록 분리해 보관합니다.
